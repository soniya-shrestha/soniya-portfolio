# Soniya Dangol – Portfolio (Angular 18, SCSS, Bootstrap 5)
Run: `npm install` then `npm start` (http://localhost:4200)
Edit content: `src/app/data/portfolio.data.ts` (add your LinkedIn/GitHub links and project details there).
Build: `npm run build` -> upload `dist/portfolio/browser`.
Deploy free: Netlify (drag the browser folder) or GitHub Pages (`ng build --base-href /repo-name/`).
Custom address (yourname.np / yourname.com): buy a domain, then point it to Netlify/GitHub Pages in the host's "Domain settings".
Photo: save yours as src/assets/photo.jpg (square, ~600px). CV: replace src/assets/Soniya_Dangol_CV.pdf when you update it.
